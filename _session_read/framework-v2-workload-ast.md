# 框架 v2：把「要不要刷」变成「在 AST 上最小化工作负载误差」

> 回应你上一条的三个点：
> 1. 决策量是"根值变化对任务的影响"——**方向对，但"任务"必须定义成 workload（含被查询的中间节点），否则"目标抵消"会误导你**；
> 2. 阈值检测是否要花隐私预算——**判据是"这个决定是否改变发布分布的支持集"**，三种解法见 §5；
> 3. AST 怎么用——**它就是 M 矩阵的来源**（弹性向量 + 闭包 + 阈值余量），见 §2。

---

## 1. 先修一个错误：目标不是 `target`，是 `workload`

你的数据里，`mcv / mch / mchc` **本身就是被查询的节点**，`anemia_class` 只是末端。因此在 ANEMIA 里：

- hb、hct 同向漂移 → `mchc = 100·hb/hct` **不变**，但 `mcv = 10·hct/rbc`、`mch = 10·hb/rbc` **都变了**；
- 如果只盯 `anemia_class`，你会得出"目标抵消 → 不刷"；但服务方下一轮问的恰恰是 mcv/mch——你返回的是旧值，**答错**。

所以「抵消」是 **node-specific（逐节点）** 的，不是全局的。
正确的目标函数是**被查询节点集合上的加权误差**，权重 = 查询频率（已知，来自对话历史）；最坏情况则对所有可能的派生函数取上确界（§7）。

> 你的直觉"不是所有根的变化都值得加噪"完全正确；`M` 矩阵就是它的精确形式：
> **`M` 的对角线是 RootGuard 的敏感度，非对角线就是"抵消/放大"本身。** RootGuard 只用了对角线。

## 2. AST 三件套

对每个可查询节点 `j`（根或派生），从 AST 上取三样东西：

| 记号 | 含义 | 怎么从 AST 得到 |
|---|---|---|
| `sources(j)` | 该节点的根闭包 | 遍历表达式树收集叶节点 |
| `a_j ∈ R^k` | 弹性向量 `∂log T_j / ∂log x_i` | 符号求导（单体式直接读指数）；线性式（MAP）取归一化系数 |
| `m_j` | 阈值节点的**边界余量** | `\|T_j(x) − 边界\| / ‖∇T_j‖`（把"离翻转还有多远"折算到输入空间） |

工作负载权重 `w_j`：该节点在历史对话中被查询的频率（归一化）；根节点若可被直接查询，也计入，`a_j = e_i`。

**核心矩阵**：

```
M = Σ_j w_j · a_j a_j^T          (k×k, 半正定)
```

`M` 一次性编码了"哪些根通过哪些被查询节点耦合、耦合多强"。

---

## 3. 误差分解：偏置 vs 方差

设刷新集合 `S ⊆ [k]`，根的对数误差 `u_i = log x̂_i − log x_i`。则节点 `j` 的对数误差 `ε_j = Σ_i a_ji u_i`，工作负载误差：

```
J(S, ε) = E[ Σ_j w_j ε_j² ]
        = b_S^T M b_S  +  Σ_{i∈S} (c_i/ε_i)² · M_ii
          └─ 偏置（陈旧）─┘   └──── 方差（新噪声）────┘
```

- `b_S[i] = Δ_i` 若 `i∉S`，否则 `0`（`Δ_i = log x_i(t) − log x_i(t_prev)`，客户端免费可得）；
- `c_i = |Δ_i|`（**增量发布**，见 v1 的 L3）或 `D_i`（重锚）；
- `M_ii` 是根 i 的"任务暴露度"。

**抵消就藏在 `b^T M b` 的交叉项里**：`a_j = (+1,−1)` 时 `M_{12} < 0`，`Δ_1 ≈ Δ_2` 让两项相消。这是可计算的，不是叙事。

## 4. 决策：2^k 枚举 + 闭式分配（**没有阈值**）

### 4.1 给定 S，分配有闭式解

最小化 `Σ_{i∈S} A_i/ε_i²`（`A_i = M_ii c_i²`），约束 `Σ_{i∈S} ε_i = E`：

```
ε_i  =  E · A_i^{1/3} / Σ_{l∈S} A_l^{1/3}          ← 仍是"弹性 1/3、漂移 2/3"
J(S) =  b_S^T M b_S  +  ( Σ_{i∈S} A_i^{1/3} )³ / E²
```

### 4.2 S 直接枚举

`k ≤ 6`（ANEMIA 是 3，FIB-4 是 4，VISCERAL 是 2），`2^k = 8~64`，**穷举即可，无需任何启发式或阈值**：

```
S* = argmin_{S ⊆ [k]}  J(S)      s.t.  J(∅) − J(S) > λ·E     （λ = 预算的影子价格）
```

**"阈值"不是被删掉了，而是被 `J(S)` 的等值面替代了。** 在 k=2 的漂移平面上，决策区域不是半平面，而是一条**围绕"补偿方向"的楔形/带状区**（见 §6 的数值例子）。任何标量阈值 `|Δ|>θ` 都无法表达这个形状——这本身就是一张好图，也是"为什么你的阈值实验效果有限"的理论解释。

### 4.3 两类节点怎么进同一个目标

| 类型 | 例子 | 进 `J` 的方式 |
|---|---|---|
| 连续（单体/线性） | mcv, mch, mchc, FIB-4, HOMA, BMI | 相对误差²，权重 `w_j` |
| 阈值/分类 | anemia_class, risk class | 翻转概率 ≈ `Φ(−m_j/σ_j)`；等价于给该节点一个**随余量衰减的权重** `w_j ∝ φ(m_j/σ_j)/σ_j` |

这解释了你的 `Recall@1` 为什么对刷新噪声极其敏感：**余量小的样本，权重被放大**，预算自然被吸到它的源根上。

## 5. 阈值/决策到底要不要花隐私预算？

### 5.1 判据（一句话）

> **如果一个决定会改变"发布值的分布"，而它又依赖私有数据，就必须计价；否则不用。**

- 「是否刷新」改变分布（刷了发新值，没刷发旧值）→ 若由私有 `Δ` 决定，**必须计价**；
- 「按 AST 静态分配」与数据无关 → **不用计价**；
- 「这次刷新的预算怎么切」改变噪声尺度 → 若由私有 `Δ` 决定，**必须计价**。

### 5.2 三种解法（按推荐度）

| 方案 | 做法 | DP 成本 | 代价 |
|---|---|---|---|
| **A. 公开规则** | `S` = "本批被提及的根全刷"（提及集合是公开的），分配按 `M` 静态 | **0** | 没有自适应，退化为你现在的周期基线 |
| **B. 指数机制（推荐）** | 从公开候选集 `{(S, 分配网格)}` 里按效用 `−J` 选一个 | `ε_a = ρ·ε_r` | 噪声预算变成 `(1−ρ)ε_r`，方差 ×`1/(1−ρ)²` |
| **C. 平滑敏感度** | 直接用 `Δ` 定噪声尺度，加平滑上界 | `ε_a`（更小） | 实现复杂，界更松 |

**关键点（也是对你图 2 那组实验的修正）**：
不要把 `ε` 花在"刷 / 不刷"这个**二值**判断上（信息量太低，白花钱）。要把 `ε_a` 花在**"选哪个 S + 怎么切"**上——候选空间大得多，同样 `ρ` 买到的信息多得多。而且 `ε_a` 是从这次刷新本来就要花的 `ε_r` 里**切出来的**，不是额外开销：

```
ε_r = ε_a + ε_v = ρ·ε_r + (1−ρ)·ε_r
```

`ρ` 的最优值可解析（方差 ∝ 1/(1−ρ)²，收益 ∝ EM 的次优间隙 `2ΔJ/ε_a`），典型落在 0.05–0.15。

### 5.3 一个容易踩的坑

**数据依赖的噪声尺度不自动满足 DP。** 若直接令 `ε_i ∝ (M_ii Δ_i²)^{1/3}`，则 `σ_i` 是 `Δ_i` 的函数，对手可从多次发布的离散度反推 `σ_i`，进而反推 `Δ_i`。所以要么走 B（离散网格 + EM），要么走 C（平滑敏感度）。**这一步不做，整套机制在理论上就不成立**——这是审稿人最容易一剑封喉的地方。

## 6. 数值例子（用你的 ANEMIA，手算一遍）

`a_mcv=(0,1,−1)`，`a_mch=(1,0,−1)`，`a_mchc=(1,−1,0)`，`a_class≈a_mchc`。
取 `w=(0.3, 0.25, 0.3, 0.15)`，得

```
M = [[ 0.55, -0.30, -0.25],
     [-0.30,  0.60, -0.30],
     [-0.25, -0.30,  0.55]]
```

**情形 ①：只刷 hb、hct 同比 +δ，rbc 不动**（Δ=(δ,δ,0)）

- 若只查 `anemia_class`：`ΔᵀMΔ = δ²(0.55+0.60−0.60)·w_class …` → 交叉项抵消，**≈0 → 不刷**；
- 若查 `mcv/mch/mchc`：`ΔᵀMΔ = 0.55δ² > 0` → **必须刷**（mcv、mch 变了）。

→ 同一个漂移、不同 workload，结论相反。**这就是"是否更新"不能只看根、也不能只看 target 的原因。**

**情形 ②：三个根同比 +δ**（Δ=(δ,δ,δ)）

`ΔᵀMΔ = δ²(1.7 − 1.7) = 0` → 所有比值不变 → **S=∅**。
但只要 rbc 多漂一点点（Δ=(δ,δ,1.2δ)），误差立刻出现 → S 必须含 rbc。

**情形 ③：完全无变化（复用）**：`Δ=0` → `J(∅)=0` → 刷新只会**增加**方差 → S=∅。这是"复用"的严格判据。

> 这三条可以直接画成 **"漂移平面上的决策区域图"**：带状区（不刷）/ 两侧楔形（刷某一个）/ 远区（全刷）。比任何阈值曲线都有说服力。

## 7. 补充：最坏情况（对手可问任意派生函数）

RootGuard 的威胁模型允许对手选任意 `f`，此时 workload 未知，目标变成

```
min_S  max_{‖a‖≤1}  aᵀ M a  =  λ_max(M)
```

即**最小化误差协方差的最大特征值**。可算、可证，是很漂亮的一节："workload-aware（加权） vs workload-agnostic（谱）"，并给出两者的差距上界。CCF-B/C 的审稿人很吃这一套。

## 8. 与你原方案的对照

| 你的表述 | v2 的精确化 |
|---|---|
| "根值变化对任务的影响" | `Δᵀ M Δ`，`M` 来自 AST；**不是**单一 target 的梯度 |
| "不是所有根变化都值得加噪" | `J(∅) − J(S) > λE` 才刷；否则复用的收益是精确的 0 成本 |
| "两个都变大但目标抵消，要不要刷" | 看**中间节点是否在 workload 里**；在 → 刷；不在 → 不刷 |

| "检测要不要花隐私预算" | 二值判断不值得买；把 `ε_a` 花在"选 S + 切分"上，从 `ε_r` 里切 |
