# PhysioNet BUN/Cr 固定总预算动态发布研究

**本报告记录目前定版的原 M8。主方法对应表中的 route，dynamic 用于检验强制刷新带来的收益。** 在跨源测试组，大波动层平均任务效用超过校准静态和强周期。实际购买新测量的动态分支也独立胜过两者。高预算时会话路由错过刷新机会，旧阈值没有测出最低预算节省，累计泄露结果依赖重构模型。

## 研究设计

数据为 PhysioNet 2019 的 4,390 名 ICU 患者。A 组划分为 2,585 名训练、632 名验证，B 组全部 1,173 人用于测试。每人 40 个公开编排的对话轮。用全部训练患者的真实任务极差中位数 5.6061 定义大波动层；测试中有 659 人严格超过该值。极差只用于事后分层。实际选侧可见预算与公开测量机会表；没有用当前患者的真值或最终极差作路由输入。先验和校准使用按患者 ID 哈希排序的前 48 位训练患者，各方法共用。患者独立但只留出一个数据源，测试组在早期数据审计中已做过漂移概况描述。

AutoResearch 第一轮在每个主预算及公开密度组内，顺序搜索刷新次数 1/2/3/4，首轮份额 25%/50%/70%，双根或单根包，以及 M-Opt、等分、训练梯度混合权重。2 至 39 轮内用离等分时点最近的公开机会；重合只付费一次。余款均分到实际刷新动作。第二轮补充时间融合和次数/首轮份额组合。融合以训练漂移、旧缓存方差与近似测量方差决定新观测权重。这是先前 M7 已有的后处理，本次将它用于固定次数、多时点根包计划。两轮均按各密度层哈希排序取至多 120 名验证患者、每人 4 次噪声，以全程最终 MAE 排序。动态相对静态的验证增益超过一个患者标准误才启用。选择与门槛使用同一验证集。在两轮冻结前均未按 B 组成绩调参。

强周期在同一验证组搜索 8 个周期，校准静态全额首发。旧 M7 比较保留前轮冻结的 BUN/Cr 路由、周期和首轮份额，在新数据上与其他方法采用相同训练先验。原生无校准 M-Opt 周期沿用校准周期的日程。四个主预算为 80、318.99、651.22、960，主结论四档等权。其余预算使用对数距离最近主预算的方案，旧 M7 用旧归档的对应预算方案。每名测试患者每档使用 4 次同流噪声，先求患者内均值。用患者和噪声两层配对 bootstrap 计算主要 MAE 对比，双主要对照另给出 Bonferroni 区间。其他指标区间按患者重采样，均为探索性。

低波动层中，强制动态相对静态为 0.327 [0.238, 0.415]，自动选侧后为 0.007 [-0.005, 0.021]。没有预先指定非劣界，因此不能作严格的非劣声明。两个主要对比的多重性调整区间见 two_level.csv。

四档中，仅在 B=651.22 和 960、公开批次≥8 时启用动态，均刷新一次、两根同发，并采用训练梯度混合根权重。前者首轮占 40% 且融合，后者首轮占 50% 并直接替换；其余六格复用全预算静态。未识别出单根包优势。不能将效果单独归功于包搜索。第一轮高波动路由 MAE 为 7.275，第二轮为 7.270。融合的独立贡献主要体现在强制动态实验，两轮部署路由平均表现非常接近。

## 何时值得刷，何时值得复用

同一条轨迹分别计算全额静态、缩减首轮预算后一直复用、以及真正刷新三项误差。相对静态的净收益等于刷新挽回的误差减去首轮预算代价。B=960 时，高波动层平均首轮代价为 0.496，刷新挽回 1.763，净改善 1.267。低波动层同档强制刷新净恶化 0.242。高波动组仅 27.5% 的患者在此档被路由到动态。真实净收益只能离线计算；公开采样密度作为可部署替代信号会漏掉稀疏且变化大的患者。不同预算的有害刷新数、根支出和逐根极值见 freshness.csv。

扫描原 54 档网格，inf 表示在预算上界仍未达到，四个宽松阈值受 80 的网格下限限制。iso.csv 同时给出均值判定、95% 单侧点态上界判定与共同达标的 bootstrap 比例。这里的阈值组来自先前公共合成任务，与真实高低波动测试组无关。在固定预算和相同支出下可以比较效用，不能从这些阈值推得节省总预算的比例。两根保护域和 grid ε=metric ε/999 沿用原核，各轮各根累加；主预算逐路径核对账本，全部预算核验总额。公开计划及训练先验是条件化保证的前提。

单客户端、训练样例计时，热缓存及模拟可信读取。路由决策中位约 0.02–0.03 ms，整会话静态约 0.40–0.47 ms，动态约 0.86–0.93 ms。每格 20 次独立在线随机流。在线无候选 MC 搜索。未测网络、峰值内存与大根数扩展曲线。
