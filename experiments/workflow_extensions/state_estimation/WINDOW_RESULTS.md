# 固定联合滤波后的任务感知校正：两种估计器的冻结回测

## 判断

连续根状态校正在相同 DP 发布下给出了可重复的小幅收益。它是两个预设候选中的次选，不能替代验证集选出的主分析。后续单独保留为可选的估计器；停止在当前测试集上调参，保留 M8。大样本 BUN/CR 收益约 1%，未达 5% 目标。

## 估计器与冻结流程

所有组复用强周期的全根包、发布时刻、总预算、根间分配、原生发布核和完全相同的噪声实现。首发到首次刷新前沿用同一校准锚点。不收费地修改后处理，保持一个可回答全部 AST 查询的根缓存。逐患者逐预算复算联合滤波 MAE 与上轮归档的最大差异小于 1e-14。

1. **近邻窗口估计。** 在同模板训练轨迹上重放预算计划，每人每档 48 次。用联合滤波状态、原始锚点与当次 DP 观测、刷新轮和已公开计划的复用长度检索近邻。每段从训练复用窗口分层取样，以终端 AST 样本中位数为读出目标，沿根空间线段逼近该值，再按固定比例与联合滤波状态融合。逐根窗口中位数和仅取刷新当轮标签为同库消融。未来窗口长度假定计划公开，服务阶段不读取未来真值。
2. **连续根校正。** 从传统联合滤波的正值根出发，在对数根空间拟合截距、相对训练中位数的偏移、锚点差和原始刷新观测差。各根有自己的系数，共用同一个终端 AST 损失，可联合调整多根误差。按预算分别在训练参考患者的 24 次噪声重放上拟合，窗口内每轮都计入损失，以二次惩罚限制修正幅度，最后投影回公开根域。同族消融仅改为优化标准化逐根 MAE，或优化当次 AST 误差（仍按窗口长度加权）。推断只用当前及以前的 DP 观测。

PhysioNet 只用原有 48 名参考患者训练；MIMIC 的 BUN/CR、MELD-Na、ANEMIA、FIB4 分别使用 10、10、10、11 名本模板训练患者，属于带本地训练参考库的迁移。源域 A 前 80 名验证患者用于选择。近邻的四个配置（32/128 个近邻 × 0.5/1 混合权重）验证 MAE 分别为 6.563、6.958、6.495、6.806。连续校正的 0.5/1 收缩配置为 6.541、6.525。按已记录的最小验证 MAE 规则，主候选为 128 近邻、0.5 混合，连续候选冻结为全幅校正。两族的归因对照复用各自入选超参数，未为每种损失单独寻优。

## 独立于本轮拟合的补充检查

看到两族回测后，单独检查连续候选：沿用源域 A 的冻结系数，按患者 ID 哈希排序选 512 名训练划分中未进入 48 人参考库的患者，与本轮验证/测试患者不重叠，换用新噪声种子。预先记录此次检查对象和计算方法。相对联合滤波改善 1.11% [0.69, 1.57]；相对同族逐根训练改善 2.28% [1.66, 2.91]；相对只优化当轮的 AST 方法为 −0.26% [−0.41, −0.11]。这是看到主实验后的同源补充检查，不能当作全新外部队列，也不能改变原选型判定。

## 为什么整条轨迹的收益有限

在 PhysioNet B 上，冻结锚点覆盖平均 71.19% 的轮次，贡献联合滤波全轨迹绝对误差的 76.87%。连续校正在剩余区间消掉的误差折合全轨迹约 1%。即使允许每次刷新预知未来真值、直接选择该复用段任务真值的中位数，沿用原锚点时全程 MAE 最多改善 18.62%。这是不可部署的事后上界；5% 在数学上仍有空间，本实验并未证明不可达。

BUN/CR 连续模型中，直接优化 AST 和优化逐根误差差异可重复，但从当轮标签改为完整窗口标签没有稳定增益。MELD-Na 的逐根消融甚至更优。近邻在三个小模板上的改善不能全部归因给 AST。MIMIC 的 4–5 名患者即使增加噪声重复也无法覆盖患者间差异。静态缓存与原 M8 的路由未接入新估计器，本轮无法声称完整 M8 的端到端效用已提升。

隐私结论依赖参考轨迹可公开使用或已经单独保护、计划元数据公开、原发布核满足已有会计。满足这些条件时，上述估计是后处理，不额外访问测试患者私有根，不增加其预算。没有对参考患者作新的 DP 保证，没有重测攻击成功率。
