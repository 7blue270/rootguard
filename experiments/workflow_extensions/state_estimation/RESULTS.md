# 固定发布下的任务感知多根状态估计实验

## 决策

停止本轮候选机制的优化，保留 M8。最大队列上候选方法落后于联合滤波，高波动子组及高预算均未挽回差距。四种不同 AST 中只有 FIB4 的整体点估计胜出，其不确定区间跨零。未达到全轨迹 MAE 改善 5% 且跨结构稳定获益的研发目标。

## 实验单位与冻结规则

PhysioNet 2019 的 BUN/CR 使用既有训练参考库中的 48 人、验证集前 80 人、测试集 1173 人。迁移到既有 MIMIC 四个模板时复用原患者划分，用各模板训练轨迹建立参考库。迁移的是算法和冻结参数，仍需目标域参考数据。MIMIC 各模板仅 4–5 名测试患者。既有队列曾用于 M8 研究，本轮属于冻结回测。

四档 B 为 80、318.99、651.22、960。PhysioNet 每人每档 4 次噪声重复，MIMIC 为 20 次。所有周期估计器共用同一次仿真的原始 DP 网格发布、校准锚点、时刻、根包及预算，复用期间根缓存保持不变。原版 RootGuard 在此沿用既有的一次 m-opt 加噪固定缓存定义；校准静态独立使用全预算锚点；M8 沿用冻结路由并运行自己的发布计划，MIMIC 使用原 M8 源域路由迁移。后三者是系统级比较。

AutoResearch 只在 PhysioNet 验证集比较历史权重 0.5 和 0.9，验证 MAE 分别为 6.7532 和 6.7072，随后冻结 0.9。主指标先在患者内平均噪声重复及四档预算，再在同一队列等权平均患者。区间为患者配对重抽样 1000 次得到的点态 95% 百分位区间，条件于固定的参考库和噪声重复。各模板的 MAE 单位不同，分别报告。

## 状态估计机制

独立与联合滤波都使用归一化根、校准后的观测、训练轨迹估计的间隔变化二阶矩、相同观测方差近似，以及创新过大时最多四倍的预测协方差膨胀。联合版本保留经 15% 收缩的非对角元素。

候选方法用原生网格核的似然对训练轨迹加权，每次刷新前将既往轨迹权重与均匀先验按 9:1 混合。计算读出时，参考根状态与当次原始 DP 观测按 85:15 混合；先求终端 AST 输出的加权中位数，再从逐根中位数沿最近可达参考点方向二分，近似找出与目标输出一致的根缓存。它针对当次经验后验上的终端绝对误差，未直接优化后续复用轮、分类或中间节点。

传统联合滤波与候选同时在先验、观测表示和读出上有差异。逐根中位数与任务读出共享同一后验及粒子，二者比较才隔离 AST 读出贡献。打乱对照按根分别循环置换参考患者，保留单根时间序列；它检验对根配对关系的依赖，也可能生成不自然的根组合。

PhysioNet 上，打乱根配对明显变差；保留配对的经验后验本身有价值。但在同后验上引入 AST 读出的增益只有约 0.11%，区间跨零，且逐根均值优于任务读出。ANEMIA 上 AST 相对逐根中位数改善，但相对联合滤波仍退化。单一打乱和半库实验无法推断任意训练库大小或域偏移下的表现。

## 适用边界与隐私

固定发布时刻之间缓存不动，若大跳变发生在未刷新轮，两种估计器均无法即时跟踪。大队列高波动子组的响应指标与总体方向一致。最高预算下候选退化加剧，与有限参考轨迹限制高精度读出这一解释相容；本轮不能据此单独确定原因。低波动也不同于严格恒定真值。既有静态分支作为冻结对照保留，强制动态候选在 PhysioNet 总体落后校准静态；没有证据支持将它接入 M8 后能自动保持静态收益。

估计器在服务端仅读既有 DP 发布、公开计划、AST 和固定参考库；测试真值用于原机制付费发布及离线评分。若参考数据独立且可合法视为公共或已单独保护，原发布核及其会计满足既定 DP 条件，则后处理不增加对该测试轨迹的预算。实验检查周期发布账本；此结论不覆盖训练人群的隐私，也不是对底层浮点发布实现的新形式化证明。本轮没有估计实际重构风险。
