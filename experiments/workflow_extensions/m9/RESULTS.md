# M9 端到端探索性回测

## 研究判断

保留 M9 作为可复现的研究版本，结束这批测试集上的选型。三个较大队列相对冻结 M8 的全轨迹 MAE 分别改善 12.42%、14.45%、10.35%。同一发布记录下，相比仅做联合滤波，任务校正分别改善 11.09%、14.53%、11.85%。在两个 2012 任务上，保持校正结构、训练样本、分流及付费动作相同，仅以终端 AST 损失替代逐根损失，仍改善 1.46% 和 8.82%。这是估计模块独立贡献的直接证据。

动态策略的收益有清晰的队列边界。2019 BUN/CR 用 29.7% 的会话预算组合实施单次刷新，相对强任务静态总体改善 3.47%，高波动组改善 5.67%，低波动组退化 2.59%。2012 BUN/CR 几乎全程选择静态，相对静态只改善 0.01%；2012 FIB4 半数选择刷新，平均比静态差 0.51%，配对区间跨零。数据支持在部分场景刷新；全面保持低波动效用、同时在多个高波动队列稳定超越任务静态的目标尚未达成。旧 MELD-Na 上 M9 比 M8 差 22.07%，只有四条测试记录，也不能据此替换该模板原机制。

在两个较大的 BUN/CR 队列上，固定计划下将全根减少到单根使 MAE 上升 11.22% 和 7.44%。在同一单根包上，把首发预算从 50% 提到 75% 则分别改善 6.15% 和 5.86%；这支持继续研究跨时间分配。单根包内均分与 m-opt 必然相等。2012 FIB4 的多根包内均分比 m-opt 差 0.41%，没有证据表明均分更优。当前根包排名只检验了一种基于训练变动和 RMS 权重的选包方式，不能推断最优根组合。

在同等效用下，2019 BUN/CR 达到目标 MAE 4.506，M9 的网格最低预算 592.02，比 M8 的 651.22 低 9.09%。2012 FIB4 的本地严格目标在给定网格中无人达到。所有方法在这批数据的各预算锚点都使用了完整 B，少刷新意味着付费访问次数减少；实际省预算的证据应看 B_min。M9 沿用原 DP 边界；经验重构风险没有一致改善，例如 2019 的指定 MAP 重构器对 M9 的归一化误差小于 M8。后续最值得在独立数据上验证的是，仅靠会话前公开信息能否预测“刷新相对强任务静态的增益”，并确认相应首发份额和全根刷新在该子群仍占优。

以下均为已使用过的测试记录。主效应按患者/住院记录配对，四个预算锚点等权。不同 AST 的 MAE 不跨队列相加。百分比效应为误差相对降幅，正值较好；区间为 1500 次记录级配对 bootstrap 的点态 95% 区间，条件于当前训练划分和随机数。旧模板每组仅有 4–5 条测试记录，区间不能充分反映训练和分流策略的不确定性。
