## 保护对象和发布流程

一条有限、单用户、多根轨迹单独拥有总预算 B。模板、T、查询安排、可测批次及其时间、候选根名称与冻结模型视为公开。使用会话前公开的完整机会表确定分支、收费时刻、根包及预算；适用场景需能预先给出时刻表。在此条件下，测试用户的漂移真值、任务误差和波动分层均只出现在离线评分中。

1. 使用对应模板和队列的冻结路由表，由 B 和公开批次数是否至少 8 选择计划。不在锚点的预算取对数距离最近的策略和估计器，实际收费使用传入的 B。静态首发花完整预算；动态首发花一半或四分之三。动态机会取最靠近第 11 或 21 轮的真实公开批次，平局取较早者。没有后续机会时保留未使用预算。
2. 首发覆盖所有根。单次刷新覆盖全部根，或覆盖训练先验中按 RMS 权重乘平均逐轮绝对变化排名靠前的一半根（向下取整，至少一个）。包只由参考库和模板确定。根内用原版 m-opt，候选包括在选中包内均分刷新预算。基础校准只对一次付费网格样本执行一次，部署使用 M8 的精确有界指数采样器和有理数费用。
3. 首发从边际校准状态起步。刷新按训练轨迹在实际间隔内的变化二阶矩预测协方差，非对角项收缩 15%。选择矩阵只保留已付费坐标，以这些坐标的校准观测计算新息和 Kalman 增益，用 Joseph 形式更新协方差。未测坐标可经相关性间接更新。未测坐标的原始观测残差特征置零。全根情形沿用已验证的联合滤波规则。
4. 以对数物理根为基准，按预算、静态/动态及首发/刷新阶段，对训练中位数偏差、当前网格发布偏差及锚点偏差做有界、带惩罚的联合线性校正。通过真实 AST 计算终端任务的绝对误差来拟合系数。校正后的根回到公开域，所有节点共用这一份根缓存。支付之间直接复用。校正属于输出读出，内部时序滤波保存其自身状态。
5. 2012 两队列直接载入既有 set-a 训练冻结的模型。2019 和原四模板使用各自原训练划分中至多 96 条记录拟合相同结构；每个窗口取 8 次配对噪声按时间分层抽取标签，以窗口长度加权。为兼容 MELD-Na 的裁剪和对数 AST，新增拟合路径使用实际 AST 和数值导数；无需替换公式。动态系数在全根周期上拟合，冻结后迁移到低频及部分根计划。边际校准、融合先验和 m-opt 的上下文与同队列的 M8 对照一致。

## AutoResearch 选择与归因

每个队列沿用原 split；训练、验证、测试的规模和参与拟合的 ID 见其 frozen.json。每个模板以至多 120 条哈希排序的验证轨迹，比较 7 项候选。分四档预算、两个公开密度单元，按验证全轨迹 MAE 最低冻结路由；相同分数按登记顺序取首项，空密度单元回退该预算所有验证记录。超小模板适用同样规则，其路由不确定性无法由测试噪声重复消除。原 M8 采用 original_bun.json 及原 density switch，其他模板和 2012 为该策略的迁移。原版 RootGuard 是历史约定的一次 m-opt 原始发布后复用。

| 受控比较 | 对应变化 |
|---|---|
| M9 vs no_estimator | 同分流、同发布，联合滤波与任务校正整体相对边际校准覆盖 |
| M9 vs pooled | 是否按公开密度分别选择，同一候选池 |
| M9 vs force_dynamic | 每个密度单元能否选静态，其余候选相同 |
| full vs static | 首发集中使用预算或保留一半做单次全根刷新，系统级比较 |
| package vs full | 第 21 轮目标、首发 50%、m-opt 不变，缩小根包 |
| early vs package | 只将目标轮从 21 提前至 11 |
| anchor75 vs package | 只将首发份额从 50% 提高至 75% |
| equal vs package | 只在同一刷新包内改为均分；单根包时两种分配完全相同 |
| period vs full | 每两次实测机会全根刷新与一次全根预约。刷新次数和每次费用随之变化 |

这里的“第 11/21 轮”指目标，付费时点由公开机会表对齐。每个冻表配套 iterations.csv，收录所有验证候选（包括未被采用的计划）。未在测试上重新选择。患者/住院记录的所有查询轮、预算和噪声重复均在同一划分。公开 split 无法识别的跨次住院者或跨来源重叠仍属于外推限制。

## 隐私分析

对有限公开域中的单根，物理输入先裁剪并归一化至 [0,1]，输出为 1000 个离散格点，打分为负绝对距离，敏感度不超过 1。复用 M8 的精确拒绝采样，以概率正比于 exp(−ε|x−z|/2) 输出格点。任意两个根值之间的分子比及配分函数比分别至多 exp(ε/2)，从而每次根观测满足 ε-DP。按整条轨迹替换的相邻定义，所有根和时点使用顺序组合；每次调用原始值读取接口只请求当次收费包。公开计划在读取前确定，根费按有理数重新归一到该次费用，返回账本之和不超过 B。冻结路由、滤波、缓存校正、服务端复用和 AST 查询均为公开信息与付费观测的后处理。无须为推断出的未测根额外收费。实测批次数或会话存在性若也属私密，需独立的保护机制。

真实入口使用系统安全随机源。离线配对基准使用历史浮点发布核与按记录/预算固定的实验种子，适于比较期望效用；公开种子的回放不可用作生产隐私服务。DP 论证保护待服务轨迹；发布私人训练库、用私人训练轨迹拟合和多模板同时共享同一人的预算需另作会计。本实验不认证运行时侧信道。经验风险在原始付费格点上以原参考轨迹为均匀离散先验，累积所有已付费坐标的网格似然，选后验概率最高的参考路径；统计其与被测裁剪根路径间的平均归一化绝对误差。该强观察者可看见输出服务未必公开的原始格点。指标越大表示这一特定重构器越不准，未涵盖其他先验或攻击。

## 使用和复现

仓库根目录下，实时代码使用冻结配置与只读回调：

```python
from experiments.workflow_extensions.m9.live import load
from experiments.workflow_extensions.m9 import run

ctx, config = load("2012_FIB4")
# public 需包含 T 与按时间排序的公开 events，每个事件含 turn。
# read_roots(turn, names) 在可信边界内返回相应根的物理值。
result = run(ctx, config, 960, public, read_roots)
```

回放、预算扫描、审计及报告均使用本地仓库。不覆盖 M8 或任何历史归档。

```bash
export OPENBLAS_NUM_THREADS=1
/root/miniconda3/envs/rootguard/bin/python -m experiments.workflow_extensions.m9
/root/miniconda3/envs/rootguard/bin/python -m experiments.workflow_extensions.m9.iso
/root/miniconda3/envs/rootguard/bin/python -m experiments.workflow_extensions.m9.iso_extra
/root/miniconda3/envs/rootguard/bin/python -m experiments.workflow_extensions.m9.estimator_audit
/root/miniconda3/envs/rootguard/bin/python -m experiments.workflow_extensions.m9.audit
/root/miniconda3/envs/dp3/bin/python experiments/workflow_extensions/m9/analysis.py
/root/miniconda3/envs/dp3/bin/python experiments/workflow_extensions/m9/report.py
```

主程序可在模块名后追加队列名称以限定运行范围；iso 同样支持。主效应按预算 80、318.99、651.22、960 等权，先在记录内平均，再在队列内平均，配对区间按记录重抽样。四次噪声重复不当作独立患者。单独给出 160 和 480 的对照。B_min 是在所列网格上使队列平均 MAE 首次达标的预算，不对非单调点插值，空值代表网格内未达；80 为左截断。历史阈值来自 m4_carry/real_v1_20261116/targets.json，另给目标域验证静态在 318.99、651.22 下的两档阈值。所有系统对照与消融均以原始 54 点网格计算 B_min，并与逐记录回放的四个重叠预算核对。
