# RootGuard 工作流研究实验

本分支从原版 RootGuard `8eb2560` 创建。核心源码、输入数据与示例配置沿用原版；原版附带的生成产物保留在本地，但停止 Git 跟踪。

## 目录约定

- `goal_shift/`：后续任务未知时，初始目标预算分配对后续目标效用的影响。
- `conditional_routing/`：原始数据或加噪缓存驱动条件路由时，数值与控制流程的联合隐私。
- `root_updates/`：复测、更正与根数据版本更新，以及跨版本隐私预算核算。
- `target_mismatch/`：目标函数知识不准确时，M-Opt 预算分配与真实任务效用的机制级实验；已完成探索，暂时搁置。
- `outputs/`：各方向的生成结果、日志、图表和汇总；由 `.gitignore` 忽略。

`root_updates/` 与 `target_mismatch/` 已加入独立实验代码并运行，详情见各自 README；另外两个工作流方向尚未实现。实验代码、配置及说明纳入 Git；生成产物统一写入 `outputs/<方向>/<运行标识>/`。

## 基线与复现资料

原版基线：`8eb2560`。复现工作区：`/home/rootguard`（`baseline` 分支），该目录保留既有实验结果；不要将复现结果复制到本分支的受跟踪路径中。

原版 RQ2、RQ4 的生成预算缓存不再跟踪，需要运行时可按各 RQ README 使用预计算脚本重新生成。输入数据和 `allocations.example.csv` 保持跟踪。

当前优先开展动态根属性版本更新实验，暂不推进其他方向。更新实验采用公共时间/结构下的数值轨迹距离隐私，并另做标准轨迹 LDP 校准，比较固定总预算、不同刷新计划与任务效用；不覆盖隐私更新时刻或根集合新增。
