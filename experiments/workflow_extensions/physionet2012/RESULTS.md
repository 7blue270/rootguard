# Challenge 2012：冻结迁移、首发校正与多根估计

## 结论

任务感知估计器通过本轮同发布比较：相对使用相同 192 条本地训练记录的传统联合滤波，两个 AST 上均实现超过 5% 的总体 MAE 降幅。旧连续机制直接迁移也有正效应，但 BUN/CR 只改善 1.96%；新机制 10.67% 和 12.14% 的改善需要目标域训练。

保持模型容量不变，AST 训练优于逐根训练，FIB4 的独立贡献尤其明显；跨根特征在 FIB4 贡献 5.89%，在 BUN/CR 仅 0.10%。FIB4 中完整模型的根对数误差绝对贡献总和较大，但经指数符号抵消后的终端对数误差较小。改善终端效用并不同时保证逐根准确。首发与刷新贡献也因任务而异：只校正首发，BUN/CR 从 6.297 降至 5.667；FIB4 则是只校正刷新更有效，从 11.378 降至 8.793。

两种新静态校正都比本地校准静态改善约 10%。固定周期完整动态的全轨迹 MAE 仍比新静态高 8.07% 和 2.85%。高预算 B=960 且高波动的 BUN/CR 子组，动态相对新静态改善 6.8%（点态 95% 区间 4.6%–9.2%）；该离线分层使用真值，不能用作在线免费分支选择。FIB4 的高波动组在这一预算没有类似的明确优势。建议保留冻结估计器，停止在 set-b 上调参。值得继续验证的是，仅依赖公开元数据或已付费 DP 历史，能否在独立样本中挑出值得动用预算的刷新机会。

## 实验设计

源域模型先冻结，先在 set-a 验证划分记录上轮两种候选的表现，再用 set-a 训练记录拟合新系数并用验证 MAE 决定幅度。set-b 仅做冻结评分。所有比较沿用同一原版 1000 点发布核、每记录每预算相同随机流、40 轮和原 AST；每档预算 4 次噪声重复，预算为 80、318.99、651.22、960。主指标按记录先平均重复和四档预算。两种 AST 分开汇报。

原版 RootGuard 沿用既有单次原始 m-opt 加噪定义；静态组首发花全预算，动态组首发一半，每第二个实测批次全根刷新，剩余预算平分，刷新机会不足时取最后一批。这里固定适于稀疏轨迹的周期，以隔离后处理；没有复刻 M8 的路由或各源数据的整套发布计划。高波动为极差严格大于 set-a 训练中位数；响应 MAE 取大于等于训练非零变化中位数的当轮及下一轮的并集，仅统计有事件的记录。尾部 P95 先在每条路径取第 95 百分位，再平均。刷新数不含首发。

## 候选机制与归因

旧近邻保留 128 邻居和 0.5 融合，使用原参考轨迹和原计划重建冻结库；旧连续校正直接载入上一轮相应预算的系数。BUN/CR 原参考库来自 PhysioNet 2019 的 48 条记录，FIB4 来自旧 MIMIC 的 11 条，全程沿用原先验的发布分配。另以与候选完全相同的 192 条本地训练记录重算边际校准和联合滤波协方差，保留原始发布，得到更公平的本地传统对照。

新方法在已发布根的对数空间校正。首发从校准锚点出发，刷新从联合滤波状态出发；用各根相对训练中位数的偏移、原始发布与当前估计之差、锚点与当前估计之差联合修正各根。所有输入仅来自公开计划、训练数据及已付费的 DP 观测。分别按预算、静动态和首发/刷新阶段拟合有界、有二次惩罚的线性系数，通过根状态计算实际终端 AST 绝对误差。训练每个发布区间用 8 个固定噪声重放分层选取真实窗口标签，按区间长度加权。部署时无需窗口未来真值。静态方案独立选幅，未训练自动路由。

逐根损失、只用本根特征、仅当前发布三项均用同一批训练记录并重新拟合系数，共享完整候选所选的幅度。逐根损失按各根训练样本中位数归一化；只用本根仍以联合状态为起点，隔离的是额外跨根特征；仅当前发布同时删除滤波记忆和锚点差。仅校正首发或刷新使用完整模型的冻结系数，其余阶段沿用联合滤波。

两个模板各取哈希排序前 192 条训练轨迹，BUN/CR 用前 160 条验证、FIB4 用全部 127 条验证。set-b 分别 2,990 与 654 条。0、0.5、1 三种校正幅度以整条轨迹 MAE 选择，0 表示保留原联合或静态基线。具体训练和验证 RecordID、阈值与全部系数均已落盘。

## 隐私边界与外推限制

同一动态对照重用同一次已收费的网格发布，训练/验证来自独立 RecordID。校正、查询和时间融合均为后处理。逐刷新检查预算前缀，评分真值与估计输入分离。在原有相邻关系、公开时间/根名/参与资格、受保护值按旧域截断、训练先验可用于部署等假设下，对测试轨迹沿用原 DP 预算。训练参考人群不自动获得 DP 保护；若时间、入选或拟合也需要保密，须另计。配对随机种子仅用于模拟，实际服务需保密的安全随机源。两任务在同一次住院上分别按各自的 B 实验，并发发布时应做组合会计。未检验重构攻击或认证底层浮点实现。

BUN/CR 和 FIB4 的测试群体重叠，不能视为两批独立人群。set-b 是同一 Challenge 的留出集，本地拟合结果代表带目标域训练样本的迁移；只有旧候选是冻结参数迁移。旧 MIMIC 与 Challenge 的潜在患者来源重叠无法按自然人核查。测试效用以最近实测值作为查询真值；未观测的生理状态无法评估。
