# Stage1：预先固定的协议

本阶段仅验证研究价值，不实施残差、新检测器或LLM调用。用户明确允许绕过阶段0探索门槛，但真实事件不足仍须报告。

数据：原26合成条件+真实H8=27条件；新增3模板×5模式×2长度=30压力条件；再加真实H16，共58。旧轨迹、人口均值及患者划分只读复用；H16真实患者按其H8身份映射到验证/测试，不在两个长度之间跨集合。压力轨迹按事先固定的类别状态生成，半数患者围绕第一边界、半数围绕第二边界；原函数、根域和FIB4年龄不变。采用有界log投影求解目标等式，不在生成后裁剪破坏事件；这种可行域构造不等于医学合理轨迹。

风险事件：原类别跨越。严格响应要求事件前一轮输出旧真值类别，在窗口0/1/2内输出一次旧→新真实类别转移；窗口在下一真实事件前截止。一输出变化至多匹配一事件，重复和错误变化为假事件。初始/事件前错误计失败，另外记录恢复新状态的比例。没有真事件时Recall/F1未定义；无预测时Precision未定义。稳定期错误变化率按真类别未变时输出是否变化计。延迟只在成功事件上求均值，同时报告失败率，不能把失败藏起来。

每轮：获得测量→判断刷新→更新缓存→生成当轮回答。严格当轮响应延迟0。稳定期误报排除已经匹配的合法迟到响应；原始稳定期输出变化率另外保留。RCE=100*mean(|pred−truth|/(C−1))，CMR=100*mean(pred!=truth)，当前三模板C=3。AoII使用错误持续轮数×归一化类别距离的平均，初始错误第一轮年龄为1。

A1固定额外实际K=1/2/4、初始+刷新K+1次、每次根预算B/(K+1)，公开人口均值权重同样，每第j次发布使用共同随机数。公开等间隔计划的相位−1/0/+1仅在验证集选择。Oracle优先前K个真类别事件，不足K时按固定公开等间隔候选、再按时间顺序补足；保证实际次数相同。该Oracle不是全局最优上界，私有时间使整个流程非DP。SVT不强塞入固定K主比较。

A2保留旧数值发布/SVT参考，全部总预算B；周期可用全部预算，SVT检测收费。周期1/2/4/8/16，SVT模式属性/任务，C2/4，检测比例20%/50%，阈值0.01/0.03/0.1。验证约束Recall@1≥20/50/80%、稳定期误报≤20%，为探索规则不是临床标准。在可行候选中最小化RCE、再CMR；不可行时明确标注，并只展示该系列最高验证响应的诊断候选，不能把它称满足约束。合成按模板/长度跨场景共同调参，约束中Recall平均只使用有事件场景。额外测试周期网格用于权衡展示，不事后替换验证选参。

B案例在formal.json中提前列8个，覆盖3函数、4种事件模式、2真实窗口；K2/4，B0.3/0.7。相同Oracle时刻及次数、同序号随机数，初始精确/加噪×刷新精确/加噪四组，全部非DP诊断。初始/刷新噪声可能交互，不机械分解为独立误差。

额外B诊断：在同一Oracle日程下，保持每次安排和随机数，仅改变发布预算比例，定位检测预算预留影响；冻结实际SVT日程，将输出变为精确状态，与每患者每噪声重复完全相同实际次数的Oracle精确日程比较，描述日程质量。这是非DP反事实，不是重新运行另一检测器，也不是固定预先K的A1。不将总体策略之差全部归因于检测误差。

隐私合同：T8/16、测量计划/根结构公开；d_inf为归一化0..999索引最大距离。根指数机制及有界重启AboveThreshold沿用前轮。条件过去输出固定时，任务log偏差全局Lipschitz常数sum|p_i|(hi−lo)/(999lo)，属性偏差1/999；阈值Lap(2Δ/ε)、查询Lap(4Δ/ε)，一阳性结束一块，至多C块，费用B*f/C每块；新向量B*(1−f)/(C+1)。公共计划按发布次数分配；组合上界B。标准轨迹充分ε界为999B，不等同B。验证资料视为公开；离线原始统计/报告不是DP发布。这里给出数学依据与假设，有限精度实现和系统整体未做机器形式化证明，账本通过不能代替隐私证明。

统计：每患者平均噪声后配对bootstrap1000次，逐条件区间；A1跨场景宏平均采用同患者共享抽样权重，两个长度/多场景不当作新患者。真实、旧合成与压力数据分开。区间逐项95%，没有做大量确证性假设检验/多重校正；只用于探索。条件级效应和不确定性全部保存，不仅数获胜条件。

预算B对应单个条件、一次离线重复的完整轨迹发布历史；60个随机重复不声称可在真实系统共同发布而仍只消耗B。类别稳定压力条件遇到域边界时可能没有实际属性变化，生成审计与相关患者子组另报告，不把零变化用于脱钩证据。
